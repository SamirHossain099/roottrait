# roottrait

Code and results for the manuscript *Dice overlap as a proxy for root trait error in image
segmentation* (Samir Hossain, Texas Tech University).

The installable library is in `src/roottrait/` and is documented in its own
[README](src/roottrait/README.md):

```
pip install roottrait
```

The rest of this repository reproduces every number in the manuscript.

## Layout

| Path | Contents |
|---|---|
| `src/roottrait/` | the library: traits, degradations, calibration, error decomposition, pinhole filling |
| `src/*.py` | analysis scripts, one per result; the flat modules `traits.py`, `degrade.py` etc. are thin aliases of the library |
| `results/` | every result the manuscript quotes, as JSON or CSV |
| `tests/` | unit tests of the library and tests that check the results files against the claims they support |

## Reproducing the results

Install with the analysis extras (and `train` for the trained-model arm):

```
pip install -e ".[analysis,dev]"
```

**Synthetic experiments** (CPU, under an hour):

```
python src/validate_fractal.py        # fractal estimator against analytic dimensions
python src/dose_response.py           # uncalibrated severity grids
python src/calibrated_sweep.py        # six failures calibrated to fixed Dice losses
python src/morphology_sweep.py        # four architectures x three thicknesses
python src/synthetic_summary.py       # the summary the manuscript reads
```

**PRMI** (Xu et al., 2022; Dryad, doi:10.5061/dryad.2v6wwpzp4, CC0). Download and extract the
archive, then:

```
python src/prmi_ingest.py --dir <PRMI_official>
python src/prmi_mask_census.py --dir <PRMI_official> --save-rows results/prmi_mask_census_rows.json
python src/prmi_null_baseline.py --census results/prmi_mask_census_rows.json
python src/prmi_pinholes.py --dir <PRMI_official>
python src/prmi_native_calibrated.py --dir <PRMI_official>     # calibrated failures on real masks
```

**Trained models** (one GPU; about 7.5 hours for 36 models):

```
python src/prmi_dataset.py --dir <PRMI_official> --config <cfg> --size 320
python src/prmi_study.py --configs peanut_640x480_DPI120 peanut_736x552_DPI150
python src/prmi_analysis.py --config <cfg>
python src/prmi_floor.py --config <cfg>
python src/prmi_branching.py --config <cfg>
python src/prmi_fill_threshold.py
python src/prmi_replication.py
```

Figures: `src/figures_calibrated.py`, `src/figures_prmi.py`, `src/figures_manuscript.py`.
Tables 3 and 4: `src/manuscript_tables.py`.

The per-frame predictions of the 36 trained models (about 15 GB) are not in the repository; they
are regenerated by `prmi_study.py`. Every summary computed from them is in `results/`.
